Frequency Divider Using T Flip-Flops — Technical Reference

1. Principle of Operation

A T (Toggle) Flip-Flop changes its output state on every active clock edge whenever its toggle input $T = 1$. Since two state transitions (one LOW-to-HIGH and one HIGH-to-LOW) are required to complete a single output cycle, the output waveform frequency is exactly half of the clock frequency:

$$f_{\text{out}} = \frac{f_{\text{in}}}{2}$$

2. Converting JK Flip-Flop (74LS73) to T Flip-Flop

The 74LS73 is a Dual Negative-Edge Triggered J-K Flip-Flop with individual Clear inputs. By tying both $J$ and $K$ inputs permanently to logic HIGH (+5V VCC), the flip-flop operates in its toggle mode:

3. Cascaded Frequency Division (Asynchronous Ripple Counter)

By cascading the output of each flip-flop to the clock input of the subsequent stage:

  • Stage 0 (NE555 Timer): Generates base clock frequency $f_{\text{in}}$.
  • Stage 1 (FF0 - IC1 Unit A): Clocked by NE555 $\implies f_0 = \frac{f_{\text{in}}}{2}$.
  • Stage 2 (FF1 - IC1 Unit B): Clocked by $Q_0 \implies f_1 = \frac{f_0}{2} = \frac{f_{\text{in}}}{4}$.
  • Stage 3 (FF2 - IC2 Unit A): Clocked by $Q_1 \implies f_2 = \frac{f_1}{2} = \frac{f_{\text{in}}}{8}$.
$$f_n = \frac{f_{\text{in}}}{2^n} \quad \text{for stage } n$$

Simultaneously, the states $(Q_2, Q_1, Q_0)$ function as a 3-bit binary asynchronous up-counter cycling from $000_2$ (0) to $111_2$ (7).

4. NE555 Astable Multivibrator Frequency Calculation

$$f = \frac{1.44}{(R_1 + 2 R_2) \cdot C_1}$$

In our circuit: $R_1 = 10\text{ k}\Omega$, $R_2 = 47\text{ k}\Omega$, $C_1 = 10\ \mu\text{F}$, yielding tunable laboratory frequencies from 0.2 Hz to 20 Hz.
