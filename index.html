1. Working Principle of T (Toggle) Flip-Flops

A T Flip-Flop is a clocked bistable sequential logic device with a single toggle control input T. When T = 1, the flip-flop toggles its output state on every active clock edge:

Qn+1 = Q̄n  (When T = 1 and Clock = ↓)
Output state inverts on every falling clock transition.

Because one full output cycle (rising edge + falling edge) requires two falling clock transitions, the output frequency is halved: fout = fin / 2.

2. Configuring 74LS73 Dual JK Flip-Flop into T Mode

The SN74LS73AN contains two independent negative-edge triggered J-K flip-flops. By connecting both J and K inputs permanently to +5V (Logic 1), the flip-flop is placed into continuous Toggle mode:

CLK Edge J Input K Input CLR# Output Qn+1 Operating Mode
↓ Falling 1 (+5V) 1 (+5V) 1 Q̄n (Toggles) T Flip-Flop Mode
↓ Falling 0 (GND) 0 (GND) 1 Qn (No Change) Hold State
↓ Falling 0 (GND) 1 (+5V) 1 0 (Low) Reset
↓ Falling 1 (+5V) 0 (GND) 1 1 (High) Set
X (Any) X X 0 (GND) 0 (Direct Clear) Asynchronous Reset

Cascaded Frequency Division Mathematics

In an asynchronous ripple counter configuration, each stage's output serves as the clock input for the next stage. The frequency at stage n is mathematically governed by:

fout =
fin 2n
Where n is the number of cascaded T flip-flop stages (n = 1, 2, 3...).

NE555 Astable Multivibrator Frequency Formula

f =
1.44 (R1 + 2R2) · C1
In this lab: R1 = 10 kΩ, R2 = 47 kΩ, C1 = 10 µF, generating 0.2 Hz to 20 Hz tunable clock pulses.

SN74LS73AN DIP-14 Pinout Reference

Pins 1 – 7 (Bottom Row)

  • Pin 1: 1CLK (Flip-Flop 1 Clock Input)
  • Pin 2: 1CLR# (Active-Low Clear 1) → Tied to +5V
  • Pin 3: 1K (Flip-Flop 1 K Input) → Tied to +5V
  • Pin 4: VCC (+5V Power Supply)
  • Pin 5: 2CLK (Flip-Flop 2 Clock Input)
  • Pin 6: 2CLR# (Active-Low Clear 2) → Tied to +5V
  • Pin 7: 2J (Flip-Flop 2 J Input) → Tied to +5V

Pins 8 – 14 (Top Row)

  • Pin 8: 2Q̄ (Flip-Flop 2 Inverted Output)
  • Pin 9: 2Q (Flip-Flop 2 True Output) → Q1 Output
  • Pin 10: 2K (Flip-Flop 2 K Input) → Tied to +5V
  • Pin 11: GND (Ground Return, 0V)
  • Pin 12: 1Q (Flip-Flop 1 True Output) → Q0 Output
  • Pin 13: 1Q̄ (Flip-Flop 1 Inverted Output)
  • Pin 14: 1J (Flip-Flop 1 J Input) → Tied to +5V
